• Question 1: Explain the setTimeout() and setInterval() functions in JavaScript. Howare
they used for timing events?
    In JavaScript, `setTimeout()` and `setInterval()` are two functions that are commonly used for timing events. They allow you to execute code after a specified delay or at regular intervals, respectively. Here’s a detailed explanation of each function:

     1. `setTimeout()`

    - Description: The `setTimeout()` function is used to execute a piece of code or a function after a specified delay (in milliseconds).
    - Syntax:
      javascript
      setTimeout(function, delay);
    
      or
      javascript
      setTimeout(() => {
          // code to be executed
      }, delay);
    

    - Parameters:
      - `function`: The function to be executed after the delay.
      - `delay`: The time in milliseconds to wait before executing the function.

    - Return Value: It returns a unique timeout ID that can be used to cancel the timeout using `clearTimeout()`.

    - Usage: `setTimeout()` is useful for delaying the execution of code, such as showing a message after a certain period or creating a pause before executing a function.

    Example:
    javascript
    console.log("Start");

    setTimeout(() => {
        console.log("This message is displayed after 2 seconds");
    }, 2000);

    console.log("End");

    Output:

    Start
    End
    (This message is displayed after 2 seconds)


     2. `setInterval()`

    - Description: The `setInterval()` function is used to repeatedly execute a piece of code or a function at specified intervals (in milliseconds).
    - Syntax:
      javascript
      setInterval(function, interval);
    
      or
      javascript
      setInterval(() => {
          // code to be executed
      }, interval);
    

    - Parameters:
      - `function`: The function to be executed repeatedly.
      - `interval`: The time in milliseconds between each execution of the function.

    - Return Value: It returns a unique interval ID that can be used to cancel the interval using `clearInterval()`.

    - Usage: `setInterval()` is useful for tasks that need to be performed repeatedly, such as updating a clock, polling a server, or animating elements.

    Example:
    javascript
    let count = 0;

    const intervalId = setInterval(() => {
        count++;
        console.log(`Count: ${count}`);

        // Stop the interval after 5 counts
        if (count === 5) {
            clearInterval(intervalId);
            console.log("Interval cleared");
        }
    }, 1000);

    Output:

    Count: 1
    Count: 2
    Count: 3
    Count: 4
    Count: 5
    Interval cleared


     Summary of Differences

    - Purpose:
      - `setTimeout()`: Executes a function once after a specified delay.
      - `setInterval()`: Executes a function repeatedly at specified intervals.

    - Return Value:
      - Both functions return a unique ID that can be used to cancel the execution using `clearTimeout()` for `setTimeout()` and `clearInterval()` for `setInterval()`.

    - Use Cases:
      - Use `setTimeout()` for one-time delays (e.g., showing a message after a delay).
      - Use `setInterval()` for repeated actions (e.g., updating a UI element every few seconds).

     Cancelling Timers

    To cancel a timeout or interval, you can use the following functions:

    - Canceling a Timeout:
      javascript
      const timeoutId = setTimeout(() => {
          console.log("This will not run");
      }, 2000);
    
      clearTimeout(timeoutId); // Cancels the timeout
    

    - Canceling an Interval:
      javascript
      const intervalId = setInterval(() => {
          console.log("This will not run");
      }, 1000);
    
      clearInterval(intervalId); // Cancels the interval
    

    These functions are essential for managing timing events in JavaScript, allowing developers to create dynamic and interactive web applications.

• Question 2: Provide an example of how to use setTimeout() to delay an action by 2
seconds.

    Certainly! Below is an example of how to use the `setTimeout()` function in JavaScript to delay an action by 2 seconds. In this example, we will display a message in the console after a 2-second delay.
    
     Example Code
    
    html
    <!DOCTYPE html>
    <html lang="en">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>setTimeout Example</title>
    </head>
    <body>
    
        <h1>setTimeout Example</h1>
        <button id="delayButton">Click me to see the delay</button>
    
        <script>
            // Function to be executed after the delay
            function delayedAction() {
                console.log("This message is displayed after a 2-second delay!");
                alert("This message is displayed after a 2-second delay!");
            }
    
            // Adding an event listener to the button
            document.getElementById('delayButton').addEventListener('click', function() {
                console.log("Button clicked! Waiting for 2 seconds...");
                // Using setTimeout to delay the action by 2000 milliseconds (2 seconds)
                setTimeout(delayedAction, 2000);
            });
        </script>
    
    </body>
    </html>
    
    
     Explanation
    
    1. HTML Structure:
       - The HTML document includes a heading and a button. When the button is clicked, it will trigger the delayed action.
    
    2. JavaScript:
       - We define a function called `delayedAction()` that contains the code we want to execute after the delay. In this case, it logs a message to the console and shows an alert.
       - We add an event listener to the button with the ID `delayButton`. When the button is clicked, it logs a message indicating that the button was clicked and that it will wait for 2 seconds.
       - The `setTimeout()` function is called with `delayedAction` as the first argument and `2000` (milliseconds) as the second argument, which means the `delayedAction()` function will be executed after a 2-second delay.
    
     How to Use
    1. Copy the code above into a text editor.
    2. Save the file with a `.html` extension (e.g., `setTimeoutExample.html`).
    3. Open the file in a web browser.
    4. Click the "Click me to see the delay" button. You will see a message in the console and an alert after a 2-second delay.

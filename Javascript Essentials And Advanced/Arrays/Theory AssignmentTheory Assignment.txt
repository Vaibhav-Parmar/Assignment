• Question 1: What is an array in JavaScript? How do you declare and initialize an array?
    In JavaScript, an array is a special type of object that is used to store a collection of values. Arrays can hold multiple values in a single variable and can contain elements of different types, including numbers, strings, objects, and even other arrays. They are particularly useful for managing lists of data.

     Characteristics of Arrays in JavaScript:
    - Ordered: Arrays maintain the order of elements, meaning that the first element is at index 0, the second at index 1, and so on.
    - Dynamic: Arrays can grow and shrink in size as elements are added or removed.
    - Zero-based Indexing: The index of the first element is 0, the second element is 1, and so forth.

     Declaring and Initializing an Array

    There are two common ways to declare and initialize an array in JavaScript:

    1. Using Array Literal Syntax:
       This is the most common and straightforward way to create an array.
       javascript
       // Declaring and initializing an array with values
       const fruits = ['apple', 'banana', 'orange'];
       

    2. Using the `Array` Constructor:
       You can also create an array using the `Array` constructor, although this method is less common.
       javascript
       // Declaring and initializing an array using the Array constructor
       const numbers = new Array(1, 2, 3, 4, 5);
       

     Examples

    Here are some examples of declaring and initializing arrays:

    javascript
    // Using array literal syntax
    const colors = ['red', 'green', 'blue'];

    // Using the Array constructor
    const scores = new Array(90, 85, 88);

    // An array containing different types of elements
    const mixedArray = [42, 'hello', true, null, { key: 'value' }, [1, 2, 3]];

    // Accessing elements in an array
    console.log(fruits[0]); // Outputs: apple
    console.log(numbers[2]); // Outputs: 3
    

     Summary

    - An array in JavaScript is a collection of values stored in a single variable.
    - You can declare and initialize an array using either array literal syntax or the `Array` constructor.
    - Arrays can hold multiple types of data and are indexed starting from 0. 

    Arrays are a fundamental part of JavaScript and are widely used for managing collections of data in various applications.


• Question 2: Explain the methods push(), pop(), shift(), and unshift() used in arrays.
    In JavaScript, arrays come with several built-in methods that allow you to manipulate their contents. Four commonly used methods are `push()`, `pop()`, `shift()`, and `unshift()`. Here’s a detailed explanation of each method:

     1. `push()`

    - Description: The `push()` method adds one or more elements to the end of an array and returns the new length of the array.
    - Syntax: 
      javascript
      array.push(element1, element2, ..., elementN);
      
    - Example:
      javascript
      const fruits = ['apple', 'banana'];
      const newLength = fruits.push('orange'); // Adds 'orange' to the end
      console.log(fruits); // Outputs: ['apple', 'banana', 'orange']
      console.log(newLength); // Outputs: 3
      

     2. `pop()`

    - Description: The `pop()` method removes the last element from an array and returns that element. This method changes the length of the array.
    - Syntax: 
      javascript
      const element = array.pop();
      
    - Example:
      javascript
      const fruits = ['apple', 'banana', 'orange'];
      const lastFruit = fruits.pop(); // Removes 'orange'
      console.log(fruits); // Outputs: ['apple', 'banana']
      console.log(lastFruit); // Outputs: 'orange'
      

     3. `shift()`

    - Description: The `shift()` method removes the first element from an array and returns that element. This method also changes the length of the array.
    - Syntax: 
      javascript
      const element = array.shift();
      
    - Example:
      javascript
      const fruits = ['apple', 'banana', 'orange'];
      const firstFruit = fruits.shift(); // Removes 'apple'
      console.log(fruits); // Outputs: ['banana', 'orange']
      console.log(firstFruit); // Outputs: 'apple'
      

     4. `unshift()`

    - Description: The `unshift()` method adds one or more elements to the beginning of an array and returns the new length of the array.
    - Syntax: 
      javascript
      array.unshift(element1, element2, ..., elementN);
      
    - Example:
      javascript
      const fruits = ['banana', 'orange'];
      const newLength = fruits.unshift('apple'); // Adds 'apple' to the beginning
      console.log(fruits); // Outputs: ['apple', 'banana', 'orange']
      console.log(newLength); // Outputs: 3
      

     Summary

    - `push()`: Adds elements to the end of an array.
    - `pop()`: Removes the last element from an array and returns it.
    - `shift()`: Removes the first element from an array and returns it.
    - `unshift()`: Adds elements to the beginning of an array.

    These methods are useful for managing the contents of arrays, allowing you to easily add or remove elements from either end of the array.

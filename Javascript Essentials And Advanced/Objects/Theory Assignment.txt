• Question 1: What is an object in JavaScript? How are objects different from arrays?
    In JavaScript, an object is a complex data type that allows you to store collections of data and more complex entities. Objects are key-value pairs, where each key (also known as a property) is a string (or Symbol) and the value can be of any data type, including other objects, arrays, functions, and primitive types (like numbers, strings, booleans, etc.).

     Characteristics of Objects in JavaScript:
    - Key-Value Pairs: Objects store data in the form of key-value pairs. Each key is a unique identifier for its corresponding value.
    - Dynamic: You can add, modify, or delete properties from an object at any time.
    - Reference Type: Objects are reference types, meaning that when you assign an object to a variable, you are assigning a reference to that object, not a copy of it.

     Declaring and Initializing an Object

    You can create an object using either object literal syntax or the `new Object()` constructor. The most common way is using object literal syntax:

    javascript
    // Using object literal syntax
    const person = {
        name: "John",
        age: 30,
        isStudent: false,
        greet: function() {
            console.log(`Hello, my name is ${this.name}`);
        }
    };

    // Accessing properties
    console.log(person.name); // Outputs: John
    console.log(person['age']); // Outputs: 30

    // Calling a method
    person.greet(); // Outputs: Hello, my name is John
    

     Differences Between Objects and Arrays

    While both objects and arrays are used to store collections of data, they have distinct characteristics and use cases:

    1. Structure:
       - Objects: Store data in key-value pairs. The keys are strings (or Symbols), and the values can be of any type.
       - Arrays: Store data in an ordered list. Each element is accessed by its index (a numeric value), starting from 0.

    2. Use Case:
       - Objects: Best suited for representing entities with properties and methods. For example, a person with attributes like name, age, and methods like greet.
       - Arrays: Best suited for ordered collections of items, such as a list of numbers, strings, or other objects.

    3. Iteration:
       - Objects: You typically use a `for...in` loop or `Object.keys()` to iterate over the properties.
       - Arrays: You can use a `for` loop, `forEach()`, or other array methods like `map()`, `filter()`, etc.

    4. Methods:
       - Objects: Do not have built-in methods for manipulating collections like arrays do (e.g., `push()`, `pop()`, etc.).
       - Arrays: Have a rich set of built-in methods for adding, removing, and manipulating elements.

     Summary

    - An object in JavaScript is a collection of key-value pairs, allowing for the storage of complex data structures.
    - Arrays are ordered collections of elements accessed by index, while objects are unordered collections accessed by keys.
    - Objects are ideal for representing entities with properties and methods, whereas arrays are best for managing lists of items. 

    Understanding the differences between objects and arrays is crucial for effectively using JavaScript to manage and manipulate data.


• Question 2: Explain how to access and update object properties using dot notation and
bracket notation.
    In JavaScript, you can access and update object properties using two primary methods: dot notation and bracket notation. Both methods allow you to interact with the properties of an object, but they have different syntax and use cases.

     1. Dot Notation

    Description: Dot notation is the most common way to access and update properties of an object. You use a dot (`.`) followed by the property name.

    Syntax:
    javascript
    objectName.propertyName
    

    Example:
    javascript
    const person = {
        name: "Alice",
        age: 25,
        greet: function() {
            console.log(`Hello, my name is ${this.name}`);
        }
    };

    // Accessing properties using dot notation
    console.log(person.name); // Outputs: Alice
    console.log(person.age);  // Outputs: 25

    // Updating properties using dot notation
    person.age = 26; // Update age
    console.log(person.age); // Outputs: 26

    // Calling a method using dot notation
    person.greet(); // Outputs: Hello, my name is Alice
    

     2. Bracket Notation

    Description: Bracket notation allows you to access and update properties using a string (or variable) that represents the property name. This is particularly useful when the property name is dynamic or not a valid identifier (e.g., contains spaces or special characters).

    Syntax:
    javascript
    objectName["propertyName"]
    

    Example:
    javascript
    const person = {
        name: "Alice",
        age: 25,
        "favorite color": "blue", // Property with a space in the name
        greet: function() {
            console.log(`Hello, my name is ${this.name}`);
        }
    };

    // Accessing properties using bracket notation
    console.log(person["name"]); // Outputs: Alice
    console.log(person["age"]);  // Outputs: 25
    console.log(person["favorite color"]); // Outputs: blue

    // Updating properties using bracket notation
    person["age"] = 26; // Update age
    console.log(person["age"]); // Outputs: 26

    // Using a variable to access a property
    const propertyName = "favorite color";
    console.log(person[propertyName]); // Outputs: blue

    // Calling a method using bracket notation
    person["greet"](); // Outputs: Hello, my name is Alice
    

     Summary of Differences

    - Dot Notation:
      - Easier to read and write.
      - Cannot be used with property names that are not valid identifiers (e.g., names with spaces, special characters, or starting with a number).
      - Example: `person.name`

    - Bracket Notation:
      - More flexible, allowing for dynamic property names and names that are not valid identifiers.
      - Useful when property names are stored in variables.
      - Example: `person["favorite color"]` or `person[propertyName]`

    Both dot notation and bracket notation are essential for working with objects in JavaScript, and understanding when to use each is important for effective coding.
